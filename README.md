# 選択式チューニングマシン（メタヒューリスティクス最適化比較ツール）2次元 Rastrigin 関数（最小値 $0$、探索範囲 $[-5.12, 5.12]^2$）を対象に、4種類のメタヒューリスティクス最適化アルゴリズムを対話式メニューから実行・比較し、結果をテキスト（results.txt）および CSV（results.csv）へ保存する C++ プログラムです。主な機能4つの最適化アルゴリズムを搭載山登り法（Hill Climbing）: 正規分布による近傍探索で改善解のみを採用します。焼きなまし法（Simulated Annealing）: 温度パラメータと冷却率に基づき、改悪解も一定確率で許容して局所最適解からの脱出を図ります。遺伝的アルゴリズム（Genetic Algorithm）: トーナメント選択・一様交叉・突然変異・エリート保存を行います。粒子群最適化（PSO）: 慣性重みと個体最良・群最良位置を用いて粒子速度と位置を更新します。外部設定ファイル（config.txt）対応: 起動時に config.txt を読み込み、未存在時は既定値を使用します。結果の永続化と閲覧: 実行ごとに results.txt と results.csv へ結果を追記し、メニューから内容を表示できます。ビルドと実行コンパイル例Bashg++ -std=c++17 -O2 main.cpp -o optimizer
※ ソースコード末尾の 1. } のような行番号混入がある場合は } に修正してからコンパイルしてください。実行例Bash./optimizer
